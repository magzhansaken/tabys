# Оценка функций глазами конкурента + полный перечень наших + план развития

Оценка как если бы её делал технический директор конкурента, разбирающий наш
продукт и свой рынок. Уровни по 5-балльной шкале:

- **5** — эталон рынка, лучше не делают
- **4** — сильно, на уровне лидеров
- **3** — рабочий базовый уровень
- **2** — есть, но слабо / только каркас
- **1** — заявлено, но почти нет
- **0** — отсутствует

Оценки конкурентов — по их документации. Наши — по коду (233 эндпоинта,
38 модулей, 1261 тест).

### Волна 1 — Закрыть отставания (там, где конкурент явно сильнее)

**32. Проверка Kaspi/КГД (догнать Wipon).** У Wipon `kaspi-check`, `kgd-check` —
проверка контрагента и товара по гос.базам. У нас 2/5. Сделать проверку ИИН/БИН
по КГД, статус налогоплательщика, риск-контрагент. *Ценность: высокая (КЗ-специфика).*

**33. Составной товар до конца (догнать МС).** Модель есть, UI-сборки нет.

## Резюме одним абзацем

По коду у нас **сильнейшие зоны**: офлайн-касса, AI-ввод (уникально на рынке),

маркетплейсы/1С/доставка/RFM (от МоегоСклада) — и это осознанные границы или
кандидаты плана. Главный стратегический ход — **Kaspi-магазин + AI-приёмка**:
первое даёт канал, второе — то, чего нет ни у кого.
