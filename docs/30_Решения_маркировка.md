# Часть 30 — Маркировка товаров (ИС МПТ Казахстан)

## Что разобрано (рынок KZ 2026, веб-поиск)

- **ИС МПТ** (markirovka.kz) — гос. система маркировки. Код **DataMatrix** =
  GTIN (тег 01, 14 цифр) + серийный номер (тег 21) в формате GS1.
- Обязательна: табак, обувь, лекарства, алкоголь, молочка, **пиво (с 02.2026)**,
  **моторные масла (с 02.2026)**, товары лёгкой промышленности.
- **Три точки для розницы**: приёмка (скан + сверка списка поставщика с фактом),
  хранение, **вывод из оборота при розничной продаже** (касса → ИС МПТ).
- Требуется регистрация участника оборота и API. Автоблокировка операций с
  непринятыми/уже выведенными кодами.

## Наши решения и почему

### 1. Полный цикл «принял → продал/вернул → вывел из оборота»
Приёмка со сканом → продажа с выводом из оборота → возврат в оборот. Каждый
переход пишется в журнал обмена с ИС МПТ. Это ровно требование закона: за
непроведённый вывод из оборота — штраф.

### 2. Сверка при приёмке (модель ИС МПТ)
При приёмке можно передать ожидаемый список от поставщика — система сверяет:
что привезли, чего **не хватает** (в накладной есть, не привезли), что **лишнее**
(привезли, в накладной нет). Проверено: из 3 обещанных привезли 2 + 1 левый →
система показала недостачу и лишний код.

### 3. Защита от двойной продажи — главное в маркировке
Один код маркировки = один физический экземпляр. Повторная продажа того же
кода **запрещена** (защита от подмены/серого товара). Проверено: продали код →
вторая продажа отбита; непринятый код продать нельзя.

### 4. Журнал обмена с ИС МПТ
Как у вебхуков и фискализации: без журнала не понять, ушёл ли вывод из оборота.
Каждая операция (вывод/возврат) — запись со статусом pending/ok/failed. Реестр
остатков показывает по каждому товару: на складе / продано / возвращено.

### 5. НЕ делаем заказ кодов маркировки
Осознанно из плана. Заказ кодов — забота производителя/импортёра, а не магазина
у дома (он получает уже маркированный товар). Мы закрываем розничный цикл:
принять, продать с выводом, вернуть.

## Границы (честно)
- Боевой API ИС МПТ (markirovka.kz) требует регистрации участника оборота и
  ключей — как ЭСФ и фискализация. Механика (парсинг, приёмка, вывод, журнал,
  идемпотентность, сверка) готова до границы; отправка в ИС МПТ включается по
  регистрации, доставку делает воркер.
- Заказ и эмиссия кодов — не наша зона (производитель/импортёр).
- Агрегация (коробы, транспортные упаковки) — задел на будущее; для магазина у
  дома штучный учёт достаточен.
