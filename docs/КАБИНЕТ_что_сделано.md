# Код кабинета — что заливать и куда

Запись в репозиторий мне недоступна: инструментов пуша у меня нет, а
песочница для скриптов не выходит в интернет — запрос к `api.github.com`
из неё не проходит вообще, не из-за прав. Токен из письма я не
использовал: рабочий ключ с правом записи, отправленный в переписке,
стоит отозвать и выдать новый.

Поэтому код лежит файлами. Заливка — ваши четыре команды, ниже.

---

## Два файла

```
code/admin/app/(cab)/layout.tsx   → admin/app/(cab)/layout.tsx   (замена)
code/admin/lib/ui-cab.tsx         → admin/lib/ui-cab.tsx         (новый)
```

**`ui.tsx` не тронут ни на строку.** Его читают тридцать файлов, поэтому
новые части документа лежат отдельным файлом. Ни один из 22 разделов
править не нужно — оболочка меняется целиком.

---

## Что в оболочке

Меню наверху: «Показатели» ссылкой и пять групп с раскрывающейся плашкой.
Разделы, адреса и порядок внутри групп прежние. «Подписка» переехала из
«Управления» в «Деньги» — деньги смотрят каждый месяц, настройки один раз;
право у раздела своё (`billing`), доступ этим не меняется.

Добавлено: поиск по `Ctrl + K`, «Важное» с числом, крошки
`магазин / группа / раздел`, избранное до пяти разделов, недавние разделы,
клавиши `1…6` по верхним пунктам, окно по `?`.

Соблюдено: `localStorage` только внутри `useEffect`; `<form>` нет;
`Select` не используется; адреса латиницей; имена полей данных читаются
только те, что читались раньше — `me.businessName`, `me.isOwner`,
`me.roleCode`, `access.canSell`, `access.status`, `access.reason`,
`sync.ready`. Шапка помечена `data-no-print`, иначе она полезла бы в печать
(в `BaseStyles` скрыт `aside`, а шапка теперь `header`).

### Про обращения к серверу — прочитайте это

Прежние три остались теми же: `/auth/me`, `/billing/access`,
`/admin/sync/readiness`. **Добавлено одно, и оно существующее:** поиск
товаров ходит в `/goods?q=…&limit=8` — тот самый, что уже вызывает раздел
«Склад» при наборе названия. Ходит только когда человек набрал два знака,
с задержкой 250 мс, ошибку молча гасит (нет права на товары — поиск
остаётся по разделам).

Не нравится — первая строка после комментария:

```ts
const SEARCH_GOODS = false;
```

Поиск останется по 22 разделам и продолжит работать.

### Чего в «Важном» нет и почему

Показываются два сигнала, и оба из уже загруженных ответов: продажи
закрыты (`access.canSell`) и есть неотданные данные с касс (`sync.ready`).

Остальные четыре из задания — закончившийся товар, незакрытая смена,
расхождение по смене, заявка с сайта, заказы Kaspi — требуют данных,
которых у оболочки нет. Новых обращений я не добавлял. **Нужен один
сводный ответ**, например `GET /admin/alerts`, отдающий готовый список:

```
[{ kind, tone: 'bad'|'warn', title, sub, href }]
```

Собирать его на сервере, а не шестью запросами из шапки: шапка живёт на
каждой странице, шесть запросов на каждый переход — это заметно.
Появится ответ — в оболочке меняется только `important`, разметка та же.

Ещё одно, помельче: «недавнее» — это недавние **разделы**, они считаются
в браузере. Недавние **документы** требуют журнала открытий; если он
нужен, скажите — это отдельный ответ сервера.

## Что даёт `ui-cab.tsx`

Четыре части для документа, каждая работает и на компьютере, и на 390 px:

- `Collapse` — свёртываемый блок с короткой сводкой справа и памятью
  выбора;
- `DocLines` — позиции: таблица на компьютере, карточки в три строки на
  телефоне (название и количество, штрихкод и цена, итог), как у UMAG;
- `StickyTotal` — итог, который не уезжает: сбоку на компьютере, панелью
  внизу на телефоне, главное действие рядом с цифрой;
- `ScanRow` — поле «Поиск товара / штрихкод» с кнопкой сканера (кнопка
  появляется только если передан `onScan` — обещанной и не работающей
  кнопки быть не должно).

Имена полей внутрь не попадают: страница раскладывает свои поля в
`name / barcode / qty / price / sum`. Расчёты остаются на странице.

### Правка `stock/page.tsx` — по желанию, четыре места

Оболочка работает без неё. Если захотите позиции карточками в приёмке:

```tsx
import { Collapse, DocLines, StickyTotal, ScanRow } from '../../../lib/ui-cab';
```

1. блок ввода строки → `<ScanRow value={line.q ?? ''} onChange={…} onAdd={addLine} disabled={!line.productId || !line.qty} />`
2. `<DataTable …>` со строками документа → `<DocLines lines={items.map((r) => ({ name: r.name, barcode: r.barcode, qty: r.qty, price: r.price, sum: r.price ? Number(r.qty) * Number(r.price) : null }))} />`
3. «Итого по документу» + кнопка «Провести» → `<StickyTotal value={total} action={process} actionLabel="Провести приёмку" note="Остатки вырастут…" />`
4. «Основная информация» и «Комментарий» → `<Collapse title="Основная информация" storageKey="supply-info">`

Расчёт `total` и вызов `process` не менять — они остаются как есть.

## Заливка

```
git checkout -b design/kabinet
cp code/admin/app/\(cab\)/layout.tsx  admin/app/\(cab\)/layout.tsx
cp code/admin/lib/ui-cab.tsx          admin/lib/ui-cab.tsx
node scripts/check-invariants.js && cd admin && npx next build
```

Правила-сторожа я сверил построчно: ничего из 96 не задето — `ui.tsx`
нетронут, в `admin/app` не появилось ни `'cols:`, ни второго перевода
статусов, ни серверных действий, ни кириллицы в именах файлов.

```
git add admin && git commit -m "Кабинет: меню наверх, поиск, важное, крошки, избранное"
git push -u origin design/kabinet
```

Если сборка или сторожа что-то скажут — пришлите вывод целиком, поправлю
по строкам.
