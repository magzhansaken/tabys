## 3. Что сделано в части 15 (эта работа)

1. **HTTP-слой кабинета** — `src/admin/admin.module.ts`: 13 контроллеров,
   ~90 эндпоинтов поверх протестированных сервисов (отчёты, склад,
   контрагенты, финансы, лояльность, документы, оборудование, биллинг, ИИ,
   онбординг, этикетки, импорт, фискализация). До этого сервисы были
   недостижимы по сети — кабинет физически не мог работать.
2. **Сотрудники** — приём на работу, роли, PIN, увольнение с защитой
   владельца (`/auth/employees`, `/auth/roles`). Раньше сотрудников можно
   было создать только SQL-ем из тестов.
3. **Автотриал при регистрации** — найден и закрыт баг запуска: новый
   клиент регистрировался и сразу упирался в «Нет подписки». Теперь
   пробный период «Старт» на 14 дней включается в момент регистрации.
4. **Кабинет владельца** — 12 страниц на Next.js: показатели, товары,
   склад, контрагенты (с долговой книгой), финансы (ДДС и P&L), отчёты
   (5 вкладок), лояльность, сотрудники, точки и кассы, настройки
   (чек-лист запуска, подписка, фискализация+ЭЦП, оборудование), вход,
   саморегистрация. Общий UI-набор `lib/ui.tsx`, каркас с живым статусом
   подписки и синхронизации.
5. **Тесты** — новый `adminapi.e2e.js` (34 проверки сквозного сценария по
   HTTP, включая права кассира и защиту владельца). Итог по проекту:
   **936 проверок, 0 провалов**, включая поднятие собранного кабинета.

## 4. План до боевого запуска

### Неделя 1 — код (осталось)
- [ ] Касса Flutter: экраны продажи/оплаты/смены поверх готового
      офлайн-ядра (`pos/lib`) и API `/pos/*`. Самый большой оставшийся блок.
- [ ] Кабинет: страница этикеток (API готов), импорт Excel с загрузкой
      файла (API готов), карточка товара с историей.
- [ ] Деплой: Docker-compose (Postgres 16 + сервер + кабинет), домен, TLS,
      бэкапы `pg_dump` по расписанию.

### Неделя 2 — внешние подключения (нужен человек, не код)
- [ ] Договор WebKassa или ReKassa, боевые ключи, регистрация ККМ в КГД.
- [ ] ЭЦП НУЦ РК + доступ к ИС ЭСФ; пороги ТИС — у бухгалтера.
- [ ] SMS-шлюз (коды входа и рассылки), ключ ИИ-провайдера.
- [ ] Юрист: публичная оферта и политика ПДн РК (у Wipon оферта — PDF на
      сайте, ориентир по составу есть).
- [ ] Подписка UMAG (8 800 ₸/мес) — снять реальные выгрузки для импортёра
      переезда.

### Неделя 3 — пилот
- [ ] 1–2 дружественных магазина: весы Rongta + принтер Xprinter,
      перенос базы из UMAG, неделя параллельной работы.
- [ ] Сверка: Z-отчёты с ОФД, остатки после инвентаризации, ДДС с кассой.

### Цены к запуску (позиционирование)
UMAG — 8 800 ₸/мес, Wipon Pro — тарифы по функциям, МойСклад — от ~6 900 ₸.
Наши «Старт» 6 900 ₸ и «Стандарт» 14 900 ₸ уже зашиты в биллинг с
фиксацией цены на год — аргумент против повышений UMAG.

## 5. Чем бьём каждого конкурента (для лендинга и продаж)

- **Против UMAG**: саморегистрация за 2 минуты вместо звонка менеджеру;
  автотриал; переезд в один клик из их же выгрузок; ИИ-создание товара по
  фото; цена ниже с фиксацией на год.
- **Против Wipon**: полноценные финансы (P&L с изъятиями владельца),
  средневзвешенная себестоимость, план пополнения, переезд с UMAG.
- **Против МоегоСклада**: вход по телефону, а не e-mail; офлайн-касса
  как ядро, а не приложение сбоку; документы и налоги именно РК
  (ЭСФ/СНТ/АВР) без «российского» балласта; поддержка на казахском.
