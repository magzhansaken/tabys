# Часть 36 — Акцизные марки алкоголя (УКМ)

## Что разобрано (рынок КЗ 2026, веб-поиск)

- **УКМ** (учётно-контрольная марка) — наклейка с штрих-кодом (PDF417/DataMatrix)
  на алкоголь (кроме вина наливом, пива). Выдаёт ИС Банкнотной фабрики Нацбанка.
  Содержит серию, номер, наименование, объём, крепость, данные производителя.
- **Проверка подлинности:** приложение **e-Sapa** (КГД РК + НИТ) и портал КГД
  «Проверка достоверности УКМ». По скану штрих-кода ИЛИ по серии+номеру.
  Результат: «Код присутствует в базе» + инфо, либо «УКМ не найдена».
- Новые правила: Приказ Минфина №682 от 07.11.2025.
- **Риск:** хранение/продажа немаркированного или контрафактного алкоголя —
  штрафы, конфискация, лишение лицензии. Проверка марки защищает магазин.

## Наши решения и почему

### 1. УКМ — отдельная система от ИС МПТ
Важное различие: алкоголь в КЗ идёт по **УКМ** (серия+номер, проверка через
e-Sapa/КГД), а обувь/табак/фарма — по **DataMatrix ИС МПТ** (часть 30). Это
разные системы, мы их не путаем — отдельный модуль excise.

### 2. Проверка подлинности (как e-Sapa)
Проверка УКМ по серии+номеру или скану штрих-кода. Результат: подлинная (с
данными о продукте) или не найдена (контрафакт). Проверено: подлинная водка
40% распознана; контрафакт (номер на 0) не найден с предупреждением.

### 3. Защита от контрафакта и клонов
- Немаркированный/поддельный алкоголь при приёмке **не принимается**.
- Одна марка = один экземпляр: **повторная продажа запрещена** (контрафакт
  клонирует номера). Проверено: продали марку → вторая продажа отбита; проверка
  проданной марки предупреждает о клоне.

### 4. Учёт марок и журнал
Реестр: сколько марок на складе, продано, забраковано. Журнал всех проверок
(аудит). Приёмка тоже логирует проверки.

### 5. НЕ делаем заявки на выдачу УКМ
Осознанно. Заявки на изготовление/выдачу УКМ через ИС Банкнотной фабрики — для
производителя/импортёра. Магазин у дома получает уже маркированный алкоголь и
только проверяет + учитывает.

### 6. Провайдерный паттерн
Интерфейс + Mock + e-Sapa/КГД каркас. Боевой доступ к e-Sapa/КГД по ЭЦП НУЦ РК.

## Границы (честно)
- Боевой доступ к e-Sapa/КГД — по ЭЦП НУЦ РК; механика проверки, учёта, журнала
  готова, включается провайдером.
- Разбор реального PDF417/DataMatrix штрих-кода — на стороне сканера; мы
  принимаем разобранные серию+номер (формат парсинга готов).
- Привязка продажи марки к чеку кассы — задел (поле sale_id есть); интеграция в
  кассовый поток — следующий шаг при необходимости.
