# Где что лежит

Короткая карта. Подробности — в `ЗАДАНИЕ.md`.

## Облик — правь свободно

```
renderer/styles.css        всё оформление
renderer/index.html        разметка страницы, порядок файлов
renderer/screen-sale.js    ГЛАВНЫЙ экран: товары и чек
renderer/screen-pay.js     оплата: способы, купюры, сдача
renderer/screen-paid.js    сдача после оплаты
renderer/screen-menu.js    верхняя строка и меню
renderer/screen-pin.js     код кассира
renderer/screen-shift.js   смена
renderer/screen-setup.js   привязка кассы
renderer/keyboard.js       экранная клавиатура — только вид
```

## Работа — не трогай

```
cart.js       чек: слияние строк, предел, отложенные
pay.js        оплата: купюры, сдача, смешанная
marks.js      марки: сбор, снятие вместе с товаром
age.js        возраст: год рождения, снятие позиций
discount.js   скидки: два потолка, поджатие
refund.js     возвраты: частичные, дважды не отдаём
report.js     отчёты X и Z, расхождение ящика
shift.js      смена: забытая, закрытие, пересчёт
rights.js     права: свой потолок, код старшего
scan.js       сканер: скорость, весовой штрихкод
sync.js       очередь чеков, дубли, отклонённые
net.js        связь с сервером, запас каталога
lock.js       замок при простое
app.js        связка всего
core.js       машина состояний
```

## Что зовут сборщики экранов

Каждый получает `(root, state, ctx)`. Разметку меняй как хочешь, имена
полей в `ctx` оставь — их даёт связка.

**screen-sale.js** — `goods`, `cart`, `cartDiscount`, `tabs`, `tab`,
`query`, `money`, `markBar`, `onTab`, `onSearch`, `onPick`, `onPay`,
`onLine`, `onPrice`, `onDiscount`, `onPark`, `onClear`.

**screen-pay.js** — `due`, `ways`, `lastWay`, `tenderOptions`, `money`,
`onBack`, `onPay`.

**screen-paid.js** — `view` с полями `number`, `positions`, `total`,
`change`, `changeWords`, `printNote`, `holdMs`; `money`, `onDone`.

**screen-menu.js** — `buildTopBar(root, state, ctx)` и
`buildMenu(root, state, ctx)`.
