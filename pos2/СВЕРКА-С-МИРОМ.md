# Касса «Табыс» против мировых

Сверено с тем, что требуют от кассы магазина в 2026 году: KORONA POS,
Square for Retail, NRS, IT Retail, Toast, NCR.

---

## Что есть — 17 из 17 обязательного

| Что | Зачем |
|---|---|
| Быстрая продажа | сканер отличается от человека по скорости набора |
| Штрихкод | обычный и весовой, вес прямо из кода |
| Весовой товар | «Картофель · 4,5 кг · 1 260 ₸» без ввода веса |
| Скидки | на позицию и на чек, два потолка |
| Возвраты | частичные, деньги дважды не отдаются |
| Отчёты X и Z | «без гашения» отдельно от закрытия |
| Денежный ящик | открывается и без продажи |
| Отложенный чек | покупатель ушёл за деньгами — касса свободна |
| **Работа без сети** | продажа, печать, закрытие смены; чеки уходят потом |
| Смешанная оплата | карта точно, наличными добирают |
| Маркировка | Data Matrix, без кода к оплате не пускает |
| Права кассира | свой потолок скидки, старший по коду |
| Инкассация | внесение, изъятие с причиной, сдача выручки |
| Замок при простое | три минуты — чек не пропадает |
| Два языка | русский и казахский; чек всегда русский |
| Проверка цены | «сколько стоит» без пробития в чек |
| Повтор печати | кончилась лента, отошёл провод |

**Проверка возраста** — добавлена по итогам этой сверки.

## Чего нет — и почему

**Покупатель и скидочная карта.** Нужна отдельная работа: база
покупателей, накопления, история покупок. В мини-маркете у прилавка это
задерживает очередь, а владельцу даёт мало.

**Подарочные карты.** В мини-маркетах Казахстана почти не встречаются.

**EBT/SNAP, лотерея, топливо.** Это американские нужды: продуктовые
талоны, лотерейные билеты, заправка. В Казахстане их нет.

**Самообслуживание.** Отдельная касса без кассира. Нужна другая
оболочка и другое железо.

**Несколько чеков разом.** У нас есть отложенные — этого хватает: в
магазине покупатель либо платит, либо отходит.

---

## Чего нет и это важно

**Остатки на кассе.** Кассир не видит, сколько товара на складе.
Покупатель спрашивает «есть ещё?» — идти смотреть.

**Фискальный чек (ОФД).** Отдельная работа с оператором фискальных
данных: договор, ключи, своя проверка.
