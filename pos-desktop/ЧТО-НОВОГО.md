# Касса «Табыс» — что нового

## 2.1.0

**Вход без сети для каждого кассира.** Раньше без интернета входил
только последний, кто работал на этой кассе. Кассиры сменяются:
утренний ушёл, вечерний сел — и войти не мог, а если и мог, то под
чужим именем.

Теперь касса помнит **каждого**, кто входил при связи. Без сети любой
из них входит **под своим именем**, и чеки идут на него.

Хранится не сам код, а его след, посоленный ключом устройства:
подобрать код по следу нельзя, а перенести след на другую кассу
бесполезно — там соль своя.

**Незнакомый код без сети — отказ.** Пускать по любому коду хуже, чем
не пустить: в чеках оказалось бы чужое имя.

**«Выйти» без закрытия смены.** Кассир отходит на обед или сдаёт место
сменщику — касса запирается, смена остаётся открытой. Смену закрывают
отдельно, с пересчётом денег: это разные дела.

**Ключ кассира в чеке.** Раньше хранилось только имя строкой. Две
Айгуль за год — обычное дело: одна ушла, другая пришла, и в чеках обе
«Айгуль». Теперь выручку по кассирам можно сверить.

Особенно это важно для чеков, пробитых **без сети**: они доходят до
сервера позже, и разбирают их именно по этому полю.
