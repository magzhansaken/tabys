# Табыс Касса — настольное приложение (Windows)

Настоящая программа для Windows, а не сайт в окне: ставится установщиком,
работает с диска, печатает на чековый принтер, открывает денежный ящик и
**продолжает продавать без интернета**.

## Почему Electron, а не Flutter

Flutter-версия кассы (папка `pos/`) требует для сборки компилятор Microsoft,
которого нет ни в песочнице разработчика, ни на Linux-сервере — только
облачная ферма GitHub. Electron собирается прямо здесь: проверено, установщик
получается за 3 минуты. Плата — размер: 270 МБ против 40 МБ у Flutter, потому
что внутрь едет собственный браузерный движок. Для кассового планшета это
верный размен: программа не зависит ни от установленного браузера, ни от
версии Windows.

Flutter-версия сохранена — она нужна для Android и терминалов Sunmi.

## Устройство

    electron/main.cjs     окно, права, команды со страницы
    electron/preload.cjs  мост: странице доступны РОВНО нужные команды
    electron/store.cjs    хранилище на диске, атомарная запись
    electron/printer.cjs  печать ESC/POS через очередь печати Windows
    renderer/             экраны кассы (чистый HTML/JS, без сборщика)

## Ключевые решения

**Продажа не ждёт сеть.** Чек сохраняется на диск мгновенно, на сервер уходит
фоном. Пропал интернет — касса торгует как обычно, очередь копится и уезжает
потом.

**Атомарная запись.** Данные пишутся во временный файл и переименовываются
поверх основного. Отключат свет посреди записи — касса проснётся с целым
файлом, а не с обрывком.

**Очередь печати.** Задания печатаются строго по одному: параллельная отправка
перемешивает их и рвёт ленту посреди чека.

**Печать без общего доступа.** Байты пишутся прямо в очередь печати Windows
через системную библиотеку. Не нужно включать «Общий доступ» к принтеру —
настройка, которая слетает после обновлений Windows.

**Ошибка печати не отменяет продажу.** Деньги уже приняты, чек сохранён;
кассир видит предупреждение и продолжает работу.

**Деньги в целых тенге.** Дробное представление округляется незаметно, и
столбик оплат перестаёт сходиться с итогом — владелец видит «недостачу»
на ровном месте.

**Без сборщика страниц.** Экраны — обычные HTML и JS. У соседнего проекта
белый экран после установки стоил часов, и виноват был именно сборщик,
просивший файлы по неверному пути. Здесь просить нечего.

## Сборка

    cd pos-desktop
    npm install
    USE_SYSTEM_MAKENSIS=true npx electron-builder --win nsis --x64 \
      --publish never -c.win.signAndEditExecutable=false -c.compression=store

Нужны: Node 22, `apt install nsis wine64 wine32:i386`.
Итог: `dist/Tabys-Kassa-<версия>-setup.exe`

## Чего пока нет

- Обновление по сети (сейчас — переустановка новым файлом)
- Отложенные чеки и выбор покупателя с бонусами
- Скидки на позицию
- Экранная клавиатура для планшета без физической

Всё это есть во Flutter-версии и переносится сюда по мере надобности.
